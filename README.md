# Textures plugins

Claude Code plugins for [Textures](https://textures.dev): hover textures, animated backgrounds and brand textures for agents and websites.

```
/plugin marketplace add Textures-dev/plugins
/plugin install textures@textures
```

The `textures` plugin brings the Textures skill (when and how to use Textures), the textures.dev MCP server (`search_textures`, `get_texture`) and the `/textures:texture` command ("/textures:texture the hero").

Rules-file version of the same recipe for CLAUDE.md, AGENTS.md and Cursor: https://textures.dev/agents.
